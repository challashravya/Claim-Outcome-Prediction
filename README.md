
# Claim Outcome Prediction – End-to-End ML Mini Build

## 1. Project Overview

This project predicts insurance claim outcomes using Machine Learning. It classifies claims into three categories:

- Paid
- Partially_Paid
- Denied

The project covers the complete ML workflow, from synthetic data generation and preprocessing to model training, evaluation, pipeline saving, and API deployment using FastAPI.

## 2. Objectives

- Generate a synthetic insurance claims dataset.
- Perform data cleaning and preprocessing.
- Apply feature engineering.
- Split the dataset using stratified sampling.
- Train a multi-class classification model.
- Evaluate the model using Precision, Recall, F1-score, and a Confusion Matrix.
- Save the complete ML pipeline.
- Develop a REST API for claim outcome predictions.

## 3. Technologies Used

- Python 3.13
- Pandas and NumPy
- Scikit-learn
- Random Forest Classifier
- FastAPI
- Uvicorn
- Joblib
- Pydantic

## 4. Dataset Description

The project uses 500 synthetically generated insurance claim records.

Features include:

| Feature | Description |
|---|---|
| id | Unique claim identifier |
| payer | Insurance payer |
| provider | Healthcare provider |
| cpt_code | Medical procedure code |
| diagnosis_code | Diagnosis identifier |
| billed_amount | Amount billed |
| patient_age | Patient age |
| status | Claim outcome (target) |

Target classes:
- Paid
- Partially_Paid
- Denied

The dataset is synthetic and is intended for demonstration and learning purposes.

## 5. Project Workflow

1. Generate synthetic claim records.
2. Load the dataset using Pandas.
3. Remove duplicate records and rows with missing target values.
4. Remove the ID column from model features.
5. Create an additional feature: amount_per_age.
6. Encode categorical features using OneHotEncoder.
7. Impute missing numerical and categorical values.
8. Scale numerical features using StandardScaler.
9. Split the data into training and testing sets using an 80:20 stratified split.
10. Train a Random Forest classifier with class balancing.
11. Evaluate model performance.
12. Save the complete preprocessing and model pipeline using Joblib.
13. Expose predictions through FastAPI.

## 6. Model Evaluation

Model: Random Forest Classifier

Training records: 400

Testing records: 100

Accuracy: 64%

### Classification Report

| Class | Precision | Recall | F1-score |
|---|---:|---:|---:|
| Paid | 0.70 | 0.92 | 0.80 |
| Partially_Paid | 0.27 | 0.12 | 0.17 |
| Denied | 0.50 | 0.29 | 0.36 |

### Confusion Matrix

| Actual / Predicted | Paid | Partially Paid | Denied |
|---|---:|---:|---:|
| Paid | 57 | 4 | 1 |
| Partially Paid | 18 | 3 | 3 |
| Denied | 6 | 4 | 4 |

The model performs better at identifying Paid claims than the other two classes. The results demonstrate the challenges of multi-class classification with imbalanced data.

## 8. Installation and Setup

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd Claim-Outcome-Prediction
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Generate the dataset:

```bash
python generate_data.py
```

Train the model:

```bash
python data/train_model.py
```

Start the API:

```bash
python -m uvicorn app:app --reload
```

## 9. API Usage

Open the interactive API documentation:

http://127.0.0.1:8000/docs

### Prediction Endpoint

POST /predict

Sample request:

```json
{
  "payer": "Medicare",
  "provider": "Hospital_A",
  "cpt_code": "99213",
  "diagnosis_code": "D001",
  "billed_amount": 1200,
  "patient_age": 45
}
```

Sample response:

```json
{
  "predicted_outcome": "Paid"
}
```

The prediction is generated by the trained Random Forest pipeline.
